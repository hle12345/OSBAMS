## RC1.2 hardware/rule changes (after the independent review)
1. **Pack-sense protection:** R41 47 Ω on PACK_INA and R42/R43 10 Ω on the Kelvin lines, upstream of the 1.5SMBJ48A diodes; calculation §2b = PASS (credible set: TVS current ≤ 18.5 A → ≤ 76.5 V; hot-plug ≤ 60 V; limit 85 V).
2. **Isolation rule:** custom DRC rule ≥ 1.0 mm between any HOST-net item and any controller-net item on every layer (replaces the 0.25 mm zone clearance on the island edge); `ISOLATION_CHECK.txt`.
3. **Pack-level clearance:** 0.2 mm class (IPC-2221B B4 0.13 mm × 1.5) with an INA228-courtyard exemption.
4. Board re-routed; DRC 0 violations, 0 unconnected; netlist 0 mismatches (403 pads). Cosmetic silkscreen warnings fixed. Gerbers removed from the package.

## RC1.1 hardware changes (the reason this is a new RC)
1. **ISO7721 (U7) symbol corrected** to the TI D/DWV table (2 OUTA, 3 INB, 6 OUTB, 7 INA); UART nets re-assigned at the isolator (OUTA→MCU RX, INB←MCU TX, OUTB→CP2102N RXD, INA←CP2102N TXD).
2. **CP2102N VBUS divider**: R38 22.1 kΩ (VBUS_USB → CP_VBUS_SENSE), R39 47.5 kΩ (→ GND_HOST); U6 pin 8 now on CP_VBUS_SENSE; VREGIN stays on VBUS_USB.
3. **CP2102N RSTb pull-up** R40 1 kΩ to 3V3_HOST (datasheet §2.1, found while reading it).
4. **CP2102N VDD bypass** C22 1 µF → 4.7 µF (datasheet: 4.7 µF + 0.1 µF per power pin).
5. Board re-placed/re-routed; ERC 0; DRC 0 electrical (3 silkscreen warnings), 0 unconnected; netlist vs PCB 0 mismatches (397 pads); polarity none; isolation check (`ISOLATION_CHECK.txt`): **3.0 mm** GND↔GND_HOST in the ISO7721 area on all layers, 0.25 mm zone clearance along the remaining island edge.
6. Not changed: IRLML0060 (provisional; first-article VDS/coil-current measurement is the validation item), TVS protection (analysis + sign-off item).
