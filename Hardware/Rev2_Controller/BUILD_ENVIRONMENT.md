# Build environment for OSBAMS Rev.2 RC1

RC1 is generated by scripts (not by hand-editing KiCad files) so every output can be reproduced and checked.

- **KiCad 10.0.6** (matches the file format of the owner's KiCad 10) is obtained from the official `kicad/kicad:10.0.6` Docker image by `tools/pull_kicad_image.py` (registry API, no docker daemon), unpacked in `/opt/kicad10`, and used through `tools/kc10` (chroot with this repo bind-mounted at `/work`). Inside it the build uses `kicad-cli` (ERC, DRC, Gerber/drill/pos/PDF export) and the `pcbnew` Python API.
- **Autorouter**: Freerouting 1.9.0 (jar from the Freerouting GitHub release) run under `xvfb-run`; KiCad DSN/SES exchange via `design/route.py`.
- **Host Python** (3.12 + openpyxl, reportlab, matplotlib, cairosvg) builds the BOM/PDF/report files.
- The manufacturer websites (st.com, ti.com, vishay.com, ...) are **not reachable** from the build environment (HTTP 403 policy denial), which is why the evidence register has no VERIFIED_LOCAL manufacturer entries.

Rebuild order (see `build_rc1.py`): `design/build_sch` -> `sch upgrade` -> ERC -> `design/pcbgen` -> DSN -> Freerouting -> SES import + zone fill -> DRC -> export Gerber/drill/pos/PDF -> `design/reports`.
