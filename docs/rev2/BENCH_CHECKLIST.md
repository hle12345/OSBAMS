# Bench checklist — exact physical tests, in order

Generated by `tools/gen_rev2_docs.py` from `desktop/equipment/validation.py`. Do not edit by hand.

Roles: **EDU36311A / HP E3630A** commissioning sources · **EDU34450A** primary and **HP 34401A** secondary reference DMMs · **EDUX1052G** (HP 54601B optional) timing/transient · **AD2** low-voltage protocol debugging · **EDU33212A / HP 33120A** signal injection · **6060B** the actual battery load (manual until GPIB is confirmed). OptiMate chargers are separate lab equipment and never touch the 36–42 V packs.

Order: low-energy commissioning → voltage calibration vs EDU34450A → HP 34401A cross-check → current validation → EDUX1052G timing → AD2 debugging → dry run → **only then** a real 36–42 V lithium-ion pack. Status of every step: **NOT_RUN**. Nothing here is BENCH_TESTED or HARDWARE_VALIDATED. Write each acceptance tolerance into the record *before* the run. Track results with `equipment.validation.ValidationLog` (PASS needs recorded data and the prerequisite steps PASS).


## A. Records

### A1 — Record identity of every instrument
- [ ] **Status:** NOT_RUN
- **Equipment:** all instruments
- **Procedure:** Read model, serial, asset ID and calibration-due date off each instrument (6060B, EDU34450A, HP 34401A, EDU36311A, HP E3630A, EDUX1052G, HP 54601B, EDU33212A, HP 33120A, AD2, handheld DMM). Enter in equipment/inventory.py.
- **Pass criterion:** No asset ID or calibration status left UNKNOWN for an instrument used as a reference (EDU34450A, HP 34401A, 6060B).

### A2 — Inspect the OSBAMS power path and wiring
- [ ] **Status:** NOT_RUN
- **Equipment:** handheld DMM
- **Procedure:** Read the exact Durakool DG57CM part number, shunt part number, fuse and fuse-holder part numbers, and the 12->5 V DC/DC converter(s) (the four open items in HARDWARE_FREEZE_CANDIDATE.md); check polarity labelling, wire gauge, connector type and that the shunt is in series. Continuity and polarity with the handheld DMM, power OFF, no source connected.
- **Pass criterion:** Every power-path rating written into capability.PowerPathLimits or marked unspecified.


## B. Low-energy commissioning (EDU36311A / E3630A)

### B1 — Controller and sensor bring-up
- [ ] **Status:** NOT_RUN · **Requires:** A1
- **Equipment:** USB power only; EDU36311A or HP E3630A for any sensor supply
- **Procedure:** Power the STM32 board from USB. Start the OSBAMS serial reader. Confirm INA228 and TC74 report and that Protocol v1 frames arrive with valid CRC and incrementing sequence numbers. If anything fails, go to G1 (AD2) to debug, then return here.
- **Pass criterion:** Both sensors healthy in the BOOT/SENSOR frames; frames parse with valid CRC.

### B2 — Fault-threshold and state-machine tests
- [ ] **Status:** NOT_RUN · **Requires:** B1
- **Equipment:** EDU36311A (primary) / HP E3630A (manual), EDU33212A or HP 33120A for sensor-signal injection
- **Procedure:** Drive over-voltage, under-voltage, over-temperature (simulated sensor value), sensor loss and host disconnect at the profile thresholds, supply side only, no battery and no 6060B.
- **Pass criterion:** Firmware reaches FAULT in each case and the load-enable output goes OFF.


## C. Voltage calibration (EDU34450A)

### C1 — INA228 voltage accuracy
- [ ] **Status:** NOT_RUN · **Requires:** B1
- **Equipment:** EDU36311A (CH2, and CH2+CH3 in series per the manufacturer's series-operation instructions), EDU34450A
- **Procedure:** Step 3, 5, 10, 20, 30 V (higher only via series, after reading the EDU36311A manual) up to the 44 V ceiling region. At each point record EDU34450A and OSBAMS voltage with equipment.reference.make_record('voltage', ...).
- **Pass criterion:** Records saved; error shown per point; tolerance written beforehand by the operator.

### C2 — ADC divider cross-check and disagreement fault
- [ ] **Status:** NOT_RUN · **Requires:** C1
- **Equipment:** EDU36311A, EDU34450A
- **Procedure:** Compare INA228 vs ADC voltage over 5-30 V (and series up to the supply limit); inject a deliberate divider error and confirm the disagreement fault fires.
- **Pass criterion:** Fault raised at the injected error; no false fault over the normal range.

### C3 — Temperature sensor check
- [ ] **Status:** NOT_RUN · **Requires:** A1
- **Equipment:** EDU34450A (temperature function), TC74
- **Procedure:** Compare ambient and a warmed point (hand/warm water bath, not a battery). Thermal protection is NOT validated until the TC74 works and is attached at a suitable point.
- **Pass criterion:** Records saved; 1 C TC74 resolution acknowledged in the result.


## D. Cross-check (HP 34401A)

### D1 — EDU34450A vs HP 34401A
- [ ] **Status:** NOT_RUN · **Requires:** C1
- **Equipment:** EDU36311A as the source, EDU34450A, HP 34401A
- **Procedure:** Measure the same stable voltage points (and a resistor) with both DMMs at once/alternately; record the difference with make_record(..., secondary=HP34401A, secondary_reading=...).
- **Pass criterion:** Difference recorded per point; any disagreement larger than the tolerance set beforehand is resolved before continuing.

### D2 — OSBAMS voltage vs HP 34401A
- [ ] **Status:** NOT_RUN · **Requires:** D1
- **Equipment:** EDU36311A, HP 34401A, EDU34450A
- **Procedure:** Repeat a subset of C1 points reading the HP 34401A as the independent check on the EDU34450A-calibrated OSBAMS channel.
- **Pass criterion:** OSBAMS agrees with BOTH references within the tolerance set beforehand, or the discrepancy is explained.


## E. Current measurement and 6060B

### E0 — 6060B power-up and front-panel record
- [ ] **Status:** NOT_RUN · **Requires:** A1
- **Equipment:** 6060B (manual), handheld DMM
- **Procedure:** Run the 6060B power-up self-test. Record the GPIB address setting, input range and protection settings. Use Manual6060B in OSBAMS.
- **Pass criterion:** Self-test passes; settings recorded.

### E1 — INA228 current accuracy at low current
- [ ] **Status:** NOT_RUN · **Requires:** C1
- **Equipment:** EDU36311A (CH1 into a resistor), EDU34450A in series (check its current range/fuse first), HP 34401A where practical
- **Procedure:** Drive 0.1, 0.25, 0.5, 1.0 A through the shunt. Record reference vs OSBAMS current.
- **Pass criterion:** Records saved; error vs current plotted; decide if the existing shunt is adequate at 1-3 A.

### E2 — Three-way comparison OSBAMS vs 6060B vs DMM
- [ ] **Status:** NOT_RUN · **Requires:** E0, E1, D2
- **Equipment:** EDU36311A as the source, 6060B (manual, CC), EDU34450A, HP 34401A, OSBAMS INA228
- **Procedure:** At 3 voltage points <= 30 V and currents <= 1 A (supply limit), set CC on the 6060B panel. Record voltage and current from OSBAMS, the 6060B panel readback and the DMM.
- **Pass criterion:** Records saved with 6060B readback and reference; discrepancies listed.

### E3 — Software envelope vs panel setting
- [ ] **Status:** NOT_RUN · **Requires:** E0
- **Equipment:** Dashboard permitted-current panel, 6060B panel
- **Procedure:** For 3 voltages read FINAL PERMITTED from the dashboard and confirm the operator-entered CC setting never exceeds it. Do NOT deliberately exceed 300 W on the instrument.
- **Pass criterion:** Panel value = min(profile, 10 A, 60 A, 300 W / conservative V) at each voltage.


## F. Timing (EDUX1052G)

### F1 — Contactor / load-enable timing
- [ ] **Status:** NOT_RUN · **Requires:** B1
- **Equipment:** EDUX1052G, EDU36311A (low-voltage supply through the contactor into a resistor)
- **Procedure:** Capture load-enable (PC8), coil drive, aux feedback (PC9) and downstream voltage. Measure close and open time, >= 10 repetitions. Rated probes and good grounding only.
- **Pass criterion:** Times recorded.

### F2 — Fault-shutdown and E-stop timing
- [ ] **Status:** NOT_RUN · **Requires:** F1
- **Equipment:** EDUX1052G, EDU36311A
- **Procedure:** Trigger a firmware fault and the E-stop; measure fault-to-open and E-stop-to-open time. Repeat with the MCU held in reset for the E-stop.
- **Pass criterion:** Times recorded; the contactor opens on E-stop with the firmware dead.

### F3 — Cross-check timing on the HP 54601B (optional) *(optional)*
- [ ] **Status:** NOT_RUN · **Requires:** F1
- **Equipment:** HP 54601B (secondary scope), EDUX1052G
- **Procedure:** Repeat one F1 capture on both scopes.
- **Pass criterion:** Times agree within the tolerance set beforehand.


## G. Protocol debugging (AD2)

### G1 — UART / I2C capture
- [ ] **Status:** NOT_RUN · **Requires:** B1
- **Equipment:** Analog Discovery 2 (logic analysis, UART/I2C decode)
- **Procedure:** Capture I2C: INA228 and TC74 acknowledge at their addresses. Capture UART: Protocol v1 frames decode and CRC-validate (feed a captured line to services.protocol.parse_frame). Use for debugging any B1 failure.
- **Pass criterion:** Both sensors ACK; captured frames parse with valid CRC.


## H. Orchestrator dry run (no battery)

### H1 — Orchestrator dry run on a supply 'pack'
- [ ] **Status:** NOT_RUN · **Requires:** E2, E3, F2, G1
- **Equipment:** EDU36311A CH2 as a stand-in source (NOT a battery), 6060B (manual), OSBAMS, dashboard
- **Procedure:** Create a low-voltage lithium-ion-style registry row within the supply limits (e.g. 12 V nominal, cutoff 9 V — a software dry run only, not a supported pack). Run Capacity: OCV -> safety check -> READY -> operator enables load -> lower the supply by hand through the cutoff -> verify automatic load-off request and recovery. Then DCIR.
- **Pass criterion:** All phases in order; load-off confirmed from measurement; safety checks logged. A supply does not model a battery, so no capacity/DCIR number is meaningful.

### H2 — E-stop / fault during a loaded run
- [ ] **Status:** NOT_RUN · **Requires:** H1
- **Equipment:** EDUX1052G, EDU36311A source, 6060B (manual)
- **Procedure:** During H1 press the E-stop; capture current decay and observe the orchestrator report FAULT with verified load-off.
- **Pass criterion:** Current falls to ~0; orchestrator ends FAULT/off-confirmed; times recorded.


## I. Real 36-42 V lithium-ion packs

### I1 — Intake and OCV of the first pack (Ninebot NEB1002-H, 5.2 Ah)
- [ ] **Status:** NOT_RUN · **Requires:** A2, B2, C2, C3, D2, E2, E3, F2, G1, H2
- **Equipment:** handheld DMM (polarity), EDU34450A (OCV), HP 34401A (cross-check), OSBAMS
- **Procedure:** Gate: every earlier non-optional step PASS. Inspect, check polarity, measure OCV with both DMMs, register with chemistry and a cutoff voltage. Compare OSBAMS OCV.
- **Pass criterion:** Registry row complete (chemistry, cutoff); OCV agreement recorded.

### I2 — Orchestrated CC capacity test (NEB1002-H)
- [ ] **Status:** NOT_RUN · **Requires:** I1
- **Equipment:** 6060B (manual CC <= the dashboard's FINAL PERMITTED, profile 1 A), OSBAMS, EDU34450A spot checks
- **Procedure:** Run Capacity: OCV -> safety check -> READY -> confirm -> discharge to the profile cutoff -> load OFF verified -> recovery. Spot-check voltage with the EDU34450A at start, mid and end.
- **Pass criterion:** Automatic cutoff; load-off confirmed; Ah/Wh stored; V/I spot-checks recorded; temperature below limit.

### I3 — DCIR current-step test (NEB1002-H)
- [ ] **Status:** NOT_RUN · **Requires:** I2
- **Equipment:** 6060B (manual), OSBAMS
- **Procedure:** Run DCIR as a separate test on a rested pack; repeat 3 times with rest between.
- **Pass criterion:** Three results recorded; repeatability reported (no tolerance claimed).

### I4 — Thermal observation
- [ ] **Status:** NOT_RUN · **Requires:** I2
- **Equipment:** EDU34450A temperature function, TC74
- **Procedure:** During I2/I3 compare pack-surface temperature (reference) with TC74; record peak.
- **Pass criterion:** Peak temperature recorded; stop-on-limit behaviour verified or marked untested.

### I5 — Repeat on Shenzhen Elite (12.8 Ah) then NEE1006-M (15.3 Ah)
- [ ] **Status:** NOT_RUN · **Requires:** I3
- **Equipment:** as I1-I4
- **Procedure:** Same sequence. Packs with BMS anomalies in the intake notes (blinking blue, cut wire) are inspected and judged safe BEFORE any connection.
- **Pass criterion:** Per-pack records saved; no pack connected without an inspection note.

### I6 — Passport and report reproducibility
- [ ] **Status:** NOT_RUN · **Requires:** I2
- **Equipment:** OSBAMS
- **Procedure:** Generate the report for each pack, regenerate it, and compare.
- **Pass criterion:** Reports identical except timestamps; version block present.


## J. Remote control (blocked)

### J1 — Identify the SFSU GPIB path
- [ ] **Status:** NOT_RUN · **Requires:** A1
- **Equipment:** lab inventory
- **Procedure:** USB<->GPIB adapter, LAN<->GPIB gateway or GPIB-equipped PC? Record models and the 6060B GPIB address (docs/rev2/GPIB_INTERFACE_CONFIRMATION.md).
- **Pass criterion:** A concrete interface identified and recorded.

### J2 — Verify commands against the official manuals
- [ ] **Status:** NOT_RUN · **Requires:** J1
- **Equipment:** Electronic Load Family Programming Reference Manual; 6060B/6063B Operating Manual
- **Procedure:** For each row of 6060B_DRIVER_EVIDENCE.md read the exact command, fill document + section/page, set VERIFIED.
- **Pass criterion:** Operations are enabled only when every command they need is VERIFIED.

### J3 — First remote contact on a supply, no battery
- [ ] **Status:** NOT_RUN · **Requires:** J2
- **Equipment:** 6060B + GPIB path, EDU36311A, EDU34450A
- **Procedure:** Construct Keysight6060B(interface_confirmed=True); identify, set_cc, input_on/off, measure on a supply source; compare with EDU34450A.
- **Pass criterion:** Readbacks agree with the reference; envelope guard refuses over-limit requests without writing.

### J4 — Transient observation
- [ ] **Status:** NOT_RUN · **Requires:** J3
- **Equipment:** 6060B remote, EDUX1052G (current probe/shunt)
- **Procedure:** Only if the transient commands are VERIFIED: configure a low-amplitude transient on a supply source and observe the current step on the scope.
- **Pass criterion:** Observed levels/frequency match the configuration.
